    Keyboard shortcuts

    Use Up and Down to move through the list. Single-letter keys work while the list has focus.

    Shortcuts
    KeyWhat it does
    Up, DownPrevious or next item
    Home, EndFirst or last item
    Page Up, Page DownMove ten items
    RightExpand subtasks, or move to the first subtask
    LeftCollapse subtasks, or move to the parent
    EnterOpen the actions menu for the item (or expand and collapse a group)
    plus, xToggle done (a done task gets done: and today's date)
    plus, greater than, less than, percent, asteriskWhen these turn a status on, a box asks for an optional note, for example who you are waiting on. Enter with nothing typed sets the status without a note. The note is saved under the task and shows when it is expanded. The letters x, w, p, i and b set the status straight away
    greater than, wToggle waiting on someone else
    less thanToggle waiting on me
    percent, pToggle in progress
    asterisk, iToggle important
    bToggle ongoing or major outcome
    TabMake the task a subtask of the task above it, with its notes and subtasks. On an unmarked line it also marks it as a to-do
    Shift and TabMove a subtask up a level. Tasks right after it at the old level become its subtasks
    dSet or clear the due date and the check-in date. A time works too: fri 2pm
    jJira: link, status, create
    oOpen the source file in your text editor
    uUndo the last change
    sOn a task: add a note to it, below its other notes in the file. On an unmarked line in triage: mark it as a note, attached to the task above. Shift and s marks every remaining line in the file as a note
    EnterMenu with every action, including converting a task to a note
    nAdd a task: type to search the tasks you have, pick one to add to a list, or choose Create new task. In triage, n goes to the next file
    Option and nMake a new list
    Delete or BackspaceIn a list: take the item off that list. In any other view, including triage: delete the task and its subtasks. The text stays in the file with a dollar sign at the start, and the app stops showing it. u undoes it
    Right arrow, Left arrowExpand or collapse a task to show its notes and subtasks. Tasks with notes start collapsed
    mCreate a new task straight away, without searching
    shift and nIn a list: add a note that is not a task, to the list's notes file. In triage: previous file
    lChoose which lists the task is on. With only My list, it adds or removes straight away
    shift and lAdd the task to the list you are viewing or used last, or remove it
    left bracket, right bracketPrevious or next list
    shift and mManage lists: create, rename, delete, folders, notes files
    shift and oIn a list: sort by manual order, due, check-in, date added, type or name
    gIn a list with manual order: pick up the item to reorder. Then Up, Down, Home and End move it, Enter or Escape drops it
    Option and Up, Option and DownIn a list with manual order: move the item up or down one place
    minusOpen My list
    equalsOpen All lists
    aTriage: mark the unmarked line as a to-do. The symbol keys also work on unmarked lines
    fTriage: show only files not yet reviewed or changed since review
    shift and rTriage: mark the whole file as reviewed
    1 to 9, 0Switch view: 1 all open, 2 by file, 3 by group, 4 schedule, 5 waiting on me, 6 waiting on others, 7 important, 8 in progress, 9 completed, 0 triage
    vJump to the view menu
    c or hShow or hide completed tasks
    slashJump to search
